# Enphase-Solar-Panel-Data-Analysis
This project oversees solar panel data provided via Enphase Envoy. The SQLite data used for this project was extracted from the Enphase Envoy home assistance database. Data was filtered from the last 400 days, and the project examines data from August 2025 to July 2026. The goal of this project was to document the trends and examine some of the nuances of solar panel production. Additionally, the data was graphed and visualized with Python code and PowerBI. There is a Jupyter Notebook file (enphase_solar_analysis.ipynb) attached that contains the Python code used as well as some of the findings. Excel was also used in order to filter and create a clean version of the data to view. The excel file also contains a summary of important findings and additional information (Solar_Production_Report.xlsx). If you want to examine some of the data for yourself, please refer to the 'enphase_envoy_400d.db' file. If you want to use some of the code provided in order to visualize the data for yourself or do your own analysis, simply import the 'enphase_envoy_400d.db' into Python. The first code block in the Jupyter Notebook file should help you as well.
